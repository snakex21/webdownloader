## v2.1.1 - Fixes for redirects, subdomains, large files and resume

### 🛠 Fixes
- **No more "Starting…" forever**: a download that cannot start (for example when the output folder cannot be created) now ends with a clear error instead of leaving the window waiting until Cancel.
- **Clean finish**: no late progress update can overwrite the result screen after a download has finished.
- **Subdomains and CDNs**: pages and files from other hosts are saved in their own folder (`_hosts/<host>/`), so `blog.example.com/` no longer replaces or skips `example.com/`, and a CDN's `/lib/app.js` no longer overwrites the site's own. The start site (with or without `www.`) keeps the same layout as before.
- **Redirects**: relative links of a redirected page are resolved against where the server sent the browser (`/docs` → `/docs/`), so its images, styles and subpages are no longer missing.
- **Start page moved to another site**: when the start address redirects to another host (for example `example.com` → `www.example.org`), that host becomes the downloaded site: its pages are followed and saved at the top of the folder instead of under `_hosts/`.
- **Ports**: files of another host on a non-default port go to `_hosts/<host>_<port>/`, so two servers on one host no longer overwrite each other.
- **Large downloads without an extension** (for example `/download?id=5`) are streamed to disk instead of being read into memory; only real HTML pages are kept in memory, up to 32 MB each.
- **Resume finishes stylesheets**: CSS saved by an interrupted run is rewritten on resume, and the fonts and images it uses are downloaded. This also covers stylesheets whose name does not end in `.css` (for example `style.php`).
- **Accurate progress**: the same page linked with different `#anchors`, or as `/` and `/index.html`, is queued once, so the queue and the percentage are right.
- **Cancel during start of the accurate mode** now stops the hidden browser instead of letting it start in the background.
- **Smoother window**: sizing a folder before deleting it, moving it to the Recycle Bin and saving history no longer freeze the window.
- Links to files named with `#`, `%` or spaces work offline, and very long file names are shortened so Windows can save them.

### 🧱 Under the hood
- The download engine is split into clear stages (setup, crawl loop, page processing, file downloads, finish), and unused code was removed. Downloads of example.com, docs.python.org and getbootstrap.com give byte-for-byte the same copies as before the change.
- The window and the engine exchange typed messages with fixed field names, checked by a test, so a change inside the engine can no longer break the window.

## v2.1.1 - Poprawki przekierowań, subdomen, dużych plików i wznawiania

### 🛠 Poprawki
- **Koniec z wiecznym „Rozpoczynanie…”**: pobieranie, które nie może wystartować (np. gdy nie da się utworzyć folderu docelowego), kończy się czytelnym błędem, zamiast czekać do kliknięcia Anuluj.
- **Czyste zakończenie**: spóźniona aktualizacja postępu nie nadpisuje już ekranu wyniku po zakończeniu pobierania.
- **Subdomeny i CDN**: strony i pliki z innych hostów trafiają do osobnego folderu (`_hosts/<host>/`), więc `blog.example.com/` nie zastępuje ani nie pomija już `example.com/`, a `/lib/app.js` z CDN nie nadpisuje pliku strony. Strona startowa (z `www.` lub bez) ma taki sam układ jak dotąd.
- **Przekierowania**: względne linki przekierowanej strony są rozwiązywane względem adresu docelowego (`/docs` → `/docs/`), więc jej obrazki, style i podstrony już nie giną.
- **Strona startowa przeniesiona na inną witrynę**: gdy adres startowy przekierowuje na inny host (np. `example.com` → `www.example.org`), to ten host staje się pobieraną witryną: jego strony są pobierane i zapisywane w głównym folderze zamiast w `_hosts/`.
- **Porty**: pliki innego hosta na niestandardowym porcie trafiają do `_hosts/<host>_<port>/`, więc dwa serwery na jednym hoście już się nie nadpisują.
- **Duże pliki bez rozszerzenia** (np. `/download?id=5`) są zapisywane strumieniowo na dysk zamiast wczytywania do pamięci; w pamięci trzymane są tylko prawdziwe strony HTML, do 32 MB każda.
- **Wznawianie kończy arkusze stylów**: CSS zapisany przez przerwane pobieranie jest przepisywany przy wznowieniu, a używane przez niego czcionki i obrazki są pobierane. Dotyczy to też arkuszy, których nazwa nie kończy się na `.css` (np. `style.php`).
- **Dokładny postęp**: ta sama strona podlinkowana z różnymi `#kotwicami` albo jako `/` i `/index.html` trafia do kolejki raz, więc kolejka i procent są poprawne.
- **Anulowanie podczas startu trybu dokładnego** zatrzymuje ukrytą przeglądarkę, zamiast pozwalać jej uruchomić się w tle.
- **Płynniejsze okno**: liczenie rozmiaru folderu przed usunięciem, przenoszenie go do Kosza i zapis historii nie zamrażają już okna.
- Linki do plików z `#`, `%` lub spacją w nazwie działają offline, a bardzo długie nazwy plików są skracane, żeby Windows mógł je zapisać.

### 🧱 Pod maską
- Silnik pobierania jest podzielony na czytelne etapy (przygotowanie, pętla pobierania, przetwarzanie strony, pobieranie plików, zakończenie), a nieużywany kod usunięto. Pobrania example.com, docs.python.org i getbootstrap.com dają kopie identyczne co do bajtu z tymi sprzed zmiany.
- Okno i silnik wymieniają typowane komunikaty o stałych nazwach pól, sprawdzanych testem, więc zmiana wewnątrz silnika nie może już zepsuć okna.
